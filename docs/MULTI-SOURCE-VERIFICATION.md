# 多资料可信核验

## 任务范围与持久化

`VerificationWorkflow.prepare_task` 通过现有草案建立正式核验任务。参数如下。

| 字段 | 语义 |
| --- | --- |
| `sources` | 已登记解析运行 ID 到明确授权的物理页集合。页号从 1 开始。 |
| `declarations` | 已登记清单导入 ID 到明确授权的原始行号集合。同一工作簿的不同工作表使用各自导入 ID。 |
| `roles` | 按解析运行登记 `specification`、`supplement` 或 `amendment`。至少有一份规格书。清单由导入身份区分。 |
| `as_of` | 可选适用日期，ISO 日期。没有截止日时不会判断变更通知已生效。 |
| `task_name` | 用于工作台续办。 |

正式草案要求至少一份已登记且选定行的声明清单。只有规格的任务通过现有 `observe_task` 读取事实并保留缺口。授权与页／行存在性先于证据和清单行正文读取。任务范围与经授权的行、页在 SQLite 中筛选。检查原始文件时读取字节仅用于校验已登记资产，不解析范围外页或清单行。不同范围、资料选择或重新提取产生的新事实创建新的草案身份，原草案和历史结果保留。

范围使用 `ira.verification-task-scope/v1` 记录在草案和核验运行。现有草案表的单个解析与清单外键是兼容锚点。实际配对、原页定位、清单映射和快照使用各事实的解析与导入身份。领域导出仍为 `ira.industrial-verification/v1`，可选携带任务范围、版本关系及各 finding 的修订状态。任务内的原文预览只返回与授权证据绑定的物理页。独立资料检索继续使用原入口。Agent 单资料服务边界保留。多资料任务的 Agent 补查入口拒绝执行，本轮未扩展其工具授权。

## 版本契约

1. 使用已有 `DocumentRevision` 登记同一逻辑文档的修订标签和生效日期。后续修订在 `scope.supersedes_revision_id` 指明被替代的注册修订 ID，并在 `relation_evidence` 记录原文证据 ID。
2. 已登记声明必须与两个已授权要求和同一逻辑文档吻合。主体、属性、部件、工况、适用范围和数量口径须一致。支持依据使用任务范围中的原文明确替代语句，例如 `R2 supersedes R1` 或 `R2 替代 R1`。截止日必须覆盖后续生效日。文件名、排序、载入顺序或标签大小不构成依据。
3. 机器关系依次表现为 `declared`、`supported`，也可能因缺口保持 `unresolved`。操作者查看原文后可以确认或否决。版本表单绑定当前关系快照和最近一条操作。没有人审时，支持态不赋予正式有效性。否决保留追加记录和冲突。分支替代保留阻断。
4. 人工确认的替代关系只影响相同授权范围中的对应要求。旧要求仍保留原文与历史，标为 `superseded`，本次不用于确定处置。后续要求仍须分别通过字段、来源、实体绑定与适用性四个信任门。
5. 快照包括选择范围、解析与清单哈希、导入映射、字段来源、已登记修订、版本关系状态和实际人审。已选资料字节失配或参与关系变更后，旧运行标为失效，历史处置继续可读。无关任务或另一个未选择的资产变化不改变当前结论。替换到新文件或新清单映射时需显式建新草案。

## 数据库兼容

本轮没有数据库迁移。继续使用现有 `verification_drafts`、`verification_runs` 和 `human_verification_records`，新增内容只存在于版本化 JSON 记录。版本确认作为 `category=version` 的追加人审事件，记录作用域内两条要求、关系依据和快照。旧任务保留 `human_verification/1` 快照，读写单资料任务无需重建数据库。多资料配对使用 `human_verification/2` 快照。

## 候选事实接入与缺口

后续模型提取入口的交接单元是**候选事实**。应提交来源资产、解析运行、证据及物理定位、字段原值和计算规范值、主体与部件标识、条件和计数口径，以及提取方法和不确定原因。候选须能定位到当前授权范围内的原句或单元格，字段派生须列出直接输入。无法定位时应返回缺口，例如 `FIELD_SUPPORT_UNKNOWN`、`CONTINUATION_UNVERIFIED` 或 `REVISION_RELATION_UNRESOLVED`。只有快照上的本机人工核验记录才能用于正式处置。候选接入约定不创建人审记录，也不赋予扩读资料的权限。

本版的版本支持语法、正文抽取和主体匹配均有明确边界。跨范围修订、跨型号继任、开放式条件、无表头续表、相似别名和有争议的配置聚合保留待核对。本轮交付不启用模型提取接口。
